 GitHub basics: repos, commits and branches

In GitHub I created my repository, this is like a filing cabinet for my files. 
Branch is a safe copy of the main trunk 
Commit is a dated save point.

What tripped me up: As I tried to edit an entry as i tried to edit it said your on the wrong branch that had opened an old snapshot, not the live file. 
Why it matters in security: branches and pull requests stop one huge mistake, or one attacker with stolen login details, from changing the live version.
